Transformations et isométries du plan

ILes transformations du plan

DÉF 1Transformation du plan

Une transformation f du plan 𝒫 est une application de 𝒫 dans 𝒫 telle que, pour tout point M′, il existe un unique point M tel que f(M) = M′. On dit que f est bijective.

f : 𝒫 → 𝒫,   M ↦ f(M) = M′

M′ est l'image de M ; M est l'antécédent de M′ par f.

DÉF 2Identité du plan

La transformation qui associe à tout point M le point M lui-même. On la note Id𝒫.

Id𝒫(M) = M

DÉF 3Transformation réciproque

La réciproque f−1 associe à tout point son unique antécédent par f.

f−1(M) = N  ⇔  f(N) = M

DÉF 4Composée de deux transformations

La composée de f et g, notée f ∘ g (« f rond g »), associe à tout point M le point :

f ∘ g (M) = f( g(M) )

On applique d'abord g, puis f.

Remarques :

  • En général f ∘ g ≠ g ∘ f. Si f ∘ g = g ∘ f, on dit que f et g commutent.
  • La composée est associative : (f ∘ h) ∘ g = f ∘ (h ∘ g).
  • f ∘ f−1 = f−1 ∘ f = Id𝒫.

IILes isométries du plan

DÉFIsométrie

Une isométrie est une transformation qui conserve les distances : une figure et son image ont la même forme et les mêmes dimensions.

∀ M, N ∈ 𝒫 :   f(M) f(N) = MN

Exemples : la symétrie centrale, la symétrie axiale, la translation, la rotation.

THÉORÈME

  1. La réciproque d'une isométrie est une isométrie.
  2. La composée de deux isométries est une isométrie.

DÉFPoint fixe (invariant)

M est un point fixe par f si f(M) = M.

Propriétés : une isométrie conserve…

1. l'alignement3 points alignés ont pour images 3 points alignés, dans le même ordre ; l'image d'une droite est une droite.
2. les distancesl'image d'un segment est un segment de même longueur ; l'image d'un cercle est un cercle de même rayon.
3. le parallélismeles images de deux droites parallèles sont deux droites parallèles.
4. l'orthogonalitéles images de deux droites perpendiculaires sont perpendiculaires.
5. les airesune figure et son image ont la même aire.
6. les anglesl'image d'un angle est un angle de même mesure.

THÉORÈMEIsométries et points fixes

  1. Une isométrie qui admet 3 points non alignés fixes est l'identité.
  2. Deux isométries qui coïncident sur 3 points non alignés coïncident partout.
  3. Une isométrie, différente de l'identité, qui fixe 2 points A et B est la symétrie axiale d'axe (AB).
  4. Une isométrie qui possède un unique point fixe I est une rotation de centre I.

IIILes isométries usuelles

Symétrie centrale SO

SO(A) = A′ ⇔ O est le milieu de [AA′].

C'est la rotation de centre O et d'angle π. Point fixe : O seul.

Symétrie axiale SΔ

SΔ(A) = A′ ⇔ Δ est la médiatrice de [AA′].

Points fixes : tous les points de la droite Δ.

Translation tu

La translation de vecteur u associe à tout point M le point M′ tel que :

MM′ = u
  • AB = CD ⇔ ABDC est un parallélogramme.
  • Si u = 0, alors tu = Id𝒫.
  • Une translation non nulle n'a aucun point fixe.
  • Réciproque : (tu)−1 = t−u.

Rotation R(Ω, α)

La rotation de centre Ω et d'angle α associe à tout point M le point M′ tel que :

ΩM′ = ΩM  et  (ΩM, ΩM′) ≡ α [2π]
  • Si α ≡ 0 [2π] : R = Id𝒫.
  • Si α ≡ π [2π] : R(Ω, π) = SΩ, la symétrie de centre Ω.
  • Réciproque : (R(Ω, α))−1 = R(Ω, −α).

L'essentiel à savoir par cœur

  • f ∘ g (M) = f(g(M)) : d'abord g, puis f ; en général f ∘ g ≠ g ∘ f.
  • Isométrie = conserve les distances, donc aussi l'alignement, le parallélisme, l'orthogonalité, les aires et les angles.
  • Réciproque ou composée d'isométries = isométrie.
  • SO : O milieu de [AA′] · SΔ : Δ médiatrice de [AA′] · tu : MM′ = u · R(Ω, α) : même distance à Ω, angle α.
  • Réciproques : t−u et R(Ω, −α).
